# Alpharius Rebuild：《诺克斯重建手册》

这是第一套重建内容包，用于验证通用框架。alpha.1 已接入手动、随身物品和技能判定；EPR / 房车专用自动判定仍待接入。

## 已知基线

依据本机单人版说明与先前配置记录：Build 42.21 系列；西西小屋推荐出生；第 14 天停水停电；EPR 材料需求 1.5 倍；电力设施电工 7/焊接 4，水厂电工 8/焊接 6；完成修复后关闭设施老化和随机停电；僵尸不重生但仍会迁移。

这些是内容包的当前设计基线，不应硬编码进 Core。运行时实际设置不同，则任务目标和说明必须按实际设置生成或清楚提示不匹配。

## 九章结构

| 章节 | 重点 |
|---|---|
| 最后一本手册 | 注册据点，熟悉任务系统 |
| 今晚住这里 | 出入口、床位、储物与应急撤离 |
| 第十四天之前 | 储水、食物和临时能源；过期仍可补做 |
| 道路重新开放 | 运输车辆、检查车况、首次物资往返 |
| 带着家出发 | 房车内饰和移动补给；普通运输车路线可替代 |
| 成为维修工程师 | 技能、回收、勘察、工程清单 |
| 让灯重新亮起 | 发电厂、区域变电站、据点供电验收 |
| 水重新流动 | 水厂、建筑接入、实际供水验收 |
| 这里仍有生活 | 生产、远征站、收藏和家园经营 |

已有配置讨论确认的推荐路线为路易斯维尔发电厂 → 马尔德劳变电站 → 罗斯伍德水处理厂 → 据点接入。正式 EPR 适配时仍须核对当前安装版本的设施 ID、供给区、前置和建筑状态。示例仅使用已在先前源码记录出现的发电厂与变电站 ID；其余使用需由适配器解析的角色引用，不虚构水厂 ID 或地图坐标。

## 任务设计原则

- 每次远征有目的：调查 → 查缺 → 补给 → 施工 → 返回验收。
- 学习技能时穿插实用维修与探索，避免只给一个漫长等级目标。
- 房车作为可选特色，不成为随机找车卡住整条工程主线的原因。
- 奖励支持下一阶段，不直接赠送整辆房车或整套修复材料。
- “检查据点”可以明确手动确认；“设施修复完成”必须读真实状态。
- 默认静音，不发持续警报；已完成状态可补认，无法追溯的历史行为明确说明。
- 地图扩展、服装与车辆收藏任务以实际启用清单为依据，逐项扩充。

## 样例范围

`content/alpharius-rebuild.json` 包含九章、14 个任务，无物资奖励。新增工具与急救用品自动检测。EPR 条件全部待实现适配器，会在 UI 明确显示不可用；不能把任务数据通过校验理解为已支持 EPR。

完整任务卡需逐步补足“为什么做、怎么做、判定、替代路线、奖励、下一步”。首个游戏版本先把关键路径玩通，再扩充支线。
