# 测试记录

## 0.1.0-alpha.1

32 项离线测试通过，覆盖内容合法性、重复与循环依赖、缺失适配器、检测异常、前置锁定、自动补认、完成状态保留、角色与世界范围分离、追踪上限、未来存档拒绝写入、Lua 5.1 语法、UTF-8 生成内容、B42 JSON 翻译和安装配置幂等。

游戏内测试环境：Windows，Project Zomboid 42.21.0，1920×1080，独立单人测试配置和新建测试世界，加载 Alpharius 整合包、Viewpoint 与现有光影。没有使用正式角色进行测试。

已通过真实游戏测试：

- 19 个任务加载，手动确认与前置阻挡生效。
- 持有工具自动完成；绷带与撕碎布条按等价组累计，物品不消耗。
- 真实角色电工 7 / 金工 4 阈值完成；缺失 EPR 检测适配器明确不可用。
- 任务追踪、重复确认幂等，既有 EPR 修理成本参数保持原值。
- 正常退出后重新读取磁盘存档：世界完成、角色完成、手动确认与追踪记录均恢复。
- 游戏 JSON 翻译与生成任务内容正确解码中文。

界面已核对真实游戏截图：章节、任务状态、完整中文、详情换行及按钮在原生视角正常。直接进入 Viewpoint 3D 时背景遮挡文字；关闭汉化仍复现。切到原生俯视再切回 3D 后，标准界面实现正常显示，重新打开仍可显示。此渲染状态问题保留为已知限制，不能据此声称所有 Viewpoint 场景兼容。没有随发布包加入诊断绘制替换、自动切换视角或改动全局图形设置的代码。

尚未覆盖：4K、其他游戏版本、仅原版环境的完整新开档流程、所有第三方模组组合、联机。整合包本身的既有警告不属于本项目修复范围。EPR / 房车自动检测适配器和物资奖励尚未实现。
